# MP3 Tag Reader

**Project Description:**

Developed an MP3 Tag Reader application using C programming to extract, read, and display metadata information stored in MP3 audio files. The application supports reading ID3 tag information, including song title, artist name, album name, release year, genre, and comments.

Implemented file handling techniques to open and process MP3 files in binary read mode. Used structures, pointers, and file operations to access and extract metadata from ID3 tags. Designed the application to identify tag frames, interpret their contents, and display the extracted information in a user-friendly format.

**Key Features:**
- Reads metadata from MP3 files.
- Extracts title, artist, album, year, genre, and comments.
- Supports ID3 tag parsing.
- Uses binary file handling for metadata extraction.
- Organizes extracted information using structures.
- Provides a command-line interface for displaying MP3 details.

**Technologies Used:** C Programming, File Handling, Structures, Pointers, String Handling, ID3 Metadata Processing.

**Learning Outcomes:** Gained practical experience in binary file operations, metadata extraction, pointer manipulation, structures, and modular programming in C.
